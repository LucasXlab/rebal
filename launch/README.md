# 发布物料（写了但没发）

这个目录里的内容是为发版准备的，**没有在任何平台发布过**。
发不发、什么时候发、用什么口吻发，由你自己决定。

| 文件 | 平台 | 说明 |
|---|---|---|
| `show-hn.md` | Hacker News（Show HN） | 英文，偏"工程实现"角度 |
| `reddit.md` | r/personalfinance、r/Bogleheads 等 | 英文，偏"解决什么问题"角度 |
| `v2ex.md` | V2EX（程序员 / 投资节点） | 中文，偏"我自己在用"角度 |
| `checklist.md` | — | 发布前必须做的事（远端仓库、标签、实名信息） |

发之前的建议：

1. 先把仓库推到 GitHub，确认 README 里的链接、徽章、相对路径都能打开。
2. 自己按 README 从零走一遍（在别的目录 clone 一份）。
3. 别同时发三个平台。先发一个，看完反馈再决定下一个。
