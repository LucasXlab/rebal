# V2EX（中文，未发布）

适用节点：`程序员`、`投资`（投资节点对推广更敏感，先看置顶规则）。

**标题**：写了个命令行工具，把"这个月这笔钱该买什么"变成一张能照着下单的清单

**正文**：

我同时用两边的券商：内地账户买 A 股 ETF，离岸账户买美股 ETF（VTI/BND）。每月定投的时候都要重复一遍同样的活：

1. 两个账户的持仓折算成人民币加起来
2. 算每个类别现在占比多少、离目标差多少
3. 看这笔钱够不够买一手，不够就换另一个类别

第 3 步最烦。目标说要补美股，但一手 VTI 就两三千，这个月的钱只够买一手 —— 手算的时候得一手一手往下减。

所以写了个 CLI：`rebal`。持仓放一个 CSV，跑一条命令，它给出一张订单清单：

```
方向  代码    名称        类别   股数    价格       金额  手续费
────────────────────────────────────────────────────────────────
买入  510300  沪深300ETF  A股   1,400  ¥4.073  ¥5,702.20   ¥0.00

合计 1 笔 · 买入 ¥5,702.20 · 手续费 ¥0.00 · 剩余现金 ¥297.80
执行后  美股 -7.3pp · A股 -3.4pp · 债券 +10.3pp
```

几个我特意做的决定，也是我觉得这工具跟"再平衡计算器"不一样的地方：

**它会告诉你为什么没买。** 光给一张买单是不够的 —— 你会想知道另外两个类别为什么一分钱没动。所以每个没买到/没卖的类别都带算式：

```
警告
  美股 还差 7.3pp，但一手 1 股约 ¥2,519.75，现金只剩 ¥297.80，买不起
  债券 超配 10.3pp，本次不卖出；加 --sell 可以配平
```

**默认不卖。** 会自己卖东西配平的工具，可能给你带来一笔没预料到的税。默认只用新钱买，想卖要显式加 `--sell`。

**取不到价格就报错退出，不会当成 0。** 有 12 小时缓存和 `--offline`，但缓存里没有就是没有，不猜。

**不会悄悄买错标的。** `quote_id` 的前缀决定市场（us/sh/sz/hk），如果这个市场的币种跟你配的 `currency` 对不上，它会直接拒绝继续算，而不是按错的汇率给你一张看起来很正常的单子。另外 `rebal prices` 会把行情源返回的证券名称打出来 —— 因为代码打错一个字母，很可能命中的是另一个真实存在的标的。

技术上的选择：Node ≥ 20.11，纯 ESM、纯 JS + JSDoc，没有 TypeScript 编译步骤；运行时只有两个依赖（smol-toml、csv-parse），都锁版本；61 个测试（`node:test`），测试不联网（本地假服务器）、不用固定 sleep（注入时钟）、只写临时目录。

它不做什么：不代下单、不画收益曲线、不算税、不回测。界面目前只有中文。

仓库：https://github.com/LucasXlab/rebal （MIT）

如果你也跨券商配平，想听听你怎么处理"一手太贵"这个问题 —— 是加预算、换标的，还是干脆按季度买？
