# 决定记录

本文件记录任务口径没写死、由我按"最简单、能跑通"原则做出的决定。与 SPEC 的偏离记在 `docs/deviations.md`（开发阶段开始后）。

1. **项目目录**：工作区 `/Users/you/NO` 里同时有多个并行会话在写各自的目录（同一天出现 `proj0/`、`ballast/`、`holdline/`、`driftline/` 等），且共用的 `reference/` 被删过一次。因此本项目放在独立目录 `/Users/you/NO/rebal`，自带 git 仓库；不修改工作区根的其他项目文件，也不提交根仓库。参照仓库克隆在本项目内 `reference/inkdove`，已加入 `.gitignore`；另在 `/tmp/research/inkdove-copy` 留一份副本以防再被删。
2. **不做 LLM**：核心价值是确定性算术（配置 → 价格 → 整数分配 → 订单），引入模型只会增加不可复现性和密钥负担。因此 v0.1.0 不调用任何大模型，`SPEC.md` 的非目标里写明。行情与汇率是唯一的外部依赖，都有 mock 与离线路径。
3. **命令行而非 Web**：目标用户每周跑一次，`rebal plan` 一条命令出结果；没有 GUI，所以不写 Web 前端，`DESIGN.md` 写的是终端输出规范。
4. **配置用 TOML**：需要注释、层级浅、手写友好。用 `smol-toml`（纯 JS、无依赖）。
5. **行情源选腾讯行情（qt.gtimg.cn）**：免费、不要 key、一次请求可取多只、覆盖 A 股/港股/美股、返回里带货币字段。2026-10-29 实测可用（见 `docs/external-apis.md`）。Stooq 现在带 JS 反爬（返回 200 但内容是验证脚本），Yahoo chart 接口本机 429，都不作为默认。
6. **汇率源选 Frankfurter**：ECB 数据、免费、无 key、文档清晰，2026-10-29 实测可用。`static` 模式允许在配置里写死汇率，完全离线。
7. **默认不卖出**：`policy.allow_sell = false`，卖出必须显式 `--sell`，避免"跑一次工具就把税卖了"。这条在 README 的"使用前须知"里也要写。
8. **不建模现金**：现金账户不参与配平（目标比例只对证券），因为现金余额在券商侧天天变、让用户维护没有价值。需要现金仓位的人用货币基金/短债 ETF 表达。非目标里写明。
9. **只支持整股/整手**：分数股会把整数分配问题变成浮点问题，v0.1.0 不碰，非目标里写明。
10. **每类资产一个"首选买入标的"**：同一资产类别下有多只标的时，用配置里的 `preferred_symbol` 决定买哪只（Portfolio Performance 的 issue #3153 就是这里含糊）。不自动挑"最便宜的那只"，避免结果不可预期。
11. **不读通用环境变量**：只认 `REBAL_` 前缀（参照 inkdove 的 `INKDOVE_` 规则）。
12. **数据不落数据库**：状态只有 `.rebal/` 下的缓存与计划 JSON 文件，便于用户备份和用 diff 看变化；不引入 SQLite。
