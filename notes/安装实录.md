## 2. 安装依赖

第一次直接 `npm ci` 失败，原因**不在项目**，是本机 npm 全局缓存目录 `/Users/you/.npm` 里有 root 属主的残留文件：

```console
$ npm ci
npm error Your cache folder contains root-owned files, due to a bug in
npm error previous versions of npm which has since been addressed.
npm error To permanently fix this problem, please run:
npm error   sudo chown -R 501:20 "/Users/you/.npm"
```

绕开方式是给本次安装单独指一个 cache 目录（不动系统目录）：

```console
$ npm ci --cache /Users/you/.npm-cache    # 或 export npm_config_cache=...
added 2 packages, and audited 3 packages in 482ms
found 0 vulnerabilities
$ ls node_modules
csv-parse  smol-toml
```

**结论**：项目依赖只有 2 个直接依赖（`csv-parse`、`smol-toml`），无原生编译、无 postinstall 脚本，安装 0 漏洞、不到 1 秒。README 里的安装步骤本身是对的；上面那次失败是这台机器的 npm 缓存历史问题，已记入「已知环境问题」。

## 6. 本次发现的问题

1. **环境问题（非项目）**：本机 `/Users/you/.npm` 有 root 属主残留，导致 `npm ci`/`npx` 报 EPERM。
   绕开：`npm ci --cache /Users/you/.npm-cache` 或 `export npm_config_cache=...`。
   项目侧不需要改；README 安装章节会补一句「若 npm 缓存报 EPERM，指一个可写 cache 目录」。
2. **文档缺口**：fresh clone 里没有 `README.md`（阶段 5 才产出），所以「按 README 走」这一步暂时是
   按 `help` 与 SPEC 走的。阶段 5 补上 README 后需要复核命令与本文一致。
