# 阶段 4 复审记录（正确性 / 安全与数据 / 新用户体验）

记录日期：2026-10-29

> **关于「三路独立审查」的说明（重要，不要误读）**
>
> 原计划是起三个只读子代理分别看正确性、安全与数据、新用户体验。本次执行环境里
> 子代理能力不可用（只有 Lead 能起），因此改为**由本 agent 分 3 轮独立 pass 完成**：
> 每一轮都重新读一遍 SPEC/DESIGN 的相关章节与对应源码，再自己列问题、自己复现，
> **不沿用上一轮的结论**。每轮之间隔了实际改动（第 1 轮修完的东西第 2、3 轮要重看）。
>
> 所以：这是**一次由同一个 agent 完成的三轮对抗式自查**，不是三个独立子代理的审查。
> 这个区别在"审稿独立性"上是有损失的——同一个人的盲区会在三轮里重复出现。

## 方法与边界

- 只读代码与规格，不先看上一轮的结论；每轮先定"这轮要查什么"，再去找反例。
- 每条结论都要求**能复现**：给出命令、输入、实际输出；不能复现的写进「误报/不改」。
- 改动只落在 `rebal/` 内；测试离线；临时目录用完即删。

## 误报与「规格如此、不改」

| 现象 | 判定 |
|---|---|
| `prices` 里示例数据全部显示「缓存」 | **不是 bug**。mock 数据时间固定为 2026-01-01，按 TTL 必然过期；SPEC §5.10 的状态词只有「新/缓存」。已在 `docs/features.md` 说明。 |
| 没配 `[fees].per_order` 时手续费是 0 且无提示 | **不是 bug**。SPEC §2.2 规定默认 0。已在 `docs/features.md` 的「已知取舍」写明真实券商要自己填。 |
| TOML 语法错时透传 smol-toml 的英文原文（带脱字符定位） | **不改**。精确定位行号比中文意译有用；第一行已经是中文。 |
| `REBAL_QUOTE_URL` 覆盖成不带 `q=` 的地址时，URL 会拼成 `http://host/xusVTI,...` | **不是 bug**。SPEC 与 `docs/external-apis.md` 都写明这个变量是"完整前缀"（默认 `https://qt.gtimg.cn/q=`）。 |
| `plan` 无单可下（退出码 4）时没有"下一步"提示行 | **暂不改**。SPEC §5.11 固定了 plan 的 stdout 结构，加一行属于改契约；警告块已经逐条解释了原因。记在这里，发布后收反馈再说。 |
