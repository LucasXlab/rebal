## 自查发现并已修的问题（28 条摘要）

完整清单见 git 历史里的提交说明，主要几类：

1. **算例口径**：执行后偏离的分母没定，三种读法给出 -8.15 / -8.42 / -8.38pp。定为
   `afterTotalBase = totalBase + cash - feesTotal`，并用 Python 逐项复算（-8.38/-6.31/+14.15 与
   -0.81/+0.18/+0.02），手续费、剩余现金、期末总资产三者相互验平。
2. **分母两套的说明**：`status` 没有 cash（分母 = 总市值，美股 -7.6pp），`plan` 的 `before` 带 cash
   （-12.2pp）。两者不是矛盾，§5.6 补了一段"两处分母的统一说法"。
3. **配置校验**：二级键、`bands`/`classes` 的多余类别、`provider` 枚举、`retries` 范围、
   可选列缺失、持仓非整手、多行价格冲突——都补了规则或明确"不报错"。
4. **数据模型**：补 `3.7 Cache`（缓存文件格式与命中条件，T23–T26 才有断言对象）；
   补 `4.1` 完整"机器码 ↔ 退出码"表（36 个码）。
5. **命令行为**：`--dir` 全局化；`--no-save`/`--no-sell` 与"不支持 `--flag=false`"对齐；
   `plan` 退出码 4 时输出 Plan 对象而不是错误对象；`prices` 的输出格式；空持仓行为；
   `check` 对未知符号降级进 `unplanned`（不让事后手工买入把核对搞失败）。
6. **错误日志**：state 目录不可写时日志没处写 → 回退到 `os.tmpdir()/rebal-last-error.log` 并打印路径。
7. **测试**：T41（原子写入造失败的方式）、T47（打码改成 `redactUrl()` 单测 + 401 假服务器）、
   T48（同秒计划 + 跨进程重启）、T49（只有表头的 CSV）；§6 风险表与 §2.1 里的测试编号全部订正。

## 没改、写明理由的

- **腾讯行情没有官方文档**：字段位置靠实测与社区长期用法，无法"按官方文档"确认。处理方式是收在
  `quotes/tencent.js` 一个文件、只用第 4 段、取不到就报错而绝不猜价格，并在 `docs/external-apis.md`
  与 README「使用前须知」写明。这是已知风险，不是遗漏。
- **`sell_capped_by_holdings` 同时下单又记 skipped**：看起来矛盾，但语义是"按持仓截断后仍然超配"，
  必须同时表达"卖了"和"没配平"。已在词表与 5.7 步骤 2 里写明。
- **两处分母不同**（`status` -7.6pp vs `plan` -12.2pp）：不是 bug，是"现在偏多少"与"这笔钱买完偏多少"
  两个不同问题，选择保留并在 §5.6 解释，而不是强行统一成一个数字。
